## Key Changes from Your Diagram

1. **PostgreSQL on EC2** (not SQLite on EFS)
   - Dedicated EC2 instance in private subnet
   - EBS for persistent storage
   - Always-on for your use case

2. **Private Subnets for ECS**
   - Django and React tasks run in private subnet
   - Only ALB is public-facing
   - NAT Gateway for outbound internet access

3. **Proper Database Setup**
   - PostgreSQL with proper backup strategy
   - Security group restricts access to ECS tasks only
   - No network filesystem issues

4. **Auto-scaling Configuration**
   - Scale to 0 when not in use (cost optimization)
   - Scale up to 3 during usage
   - Based on ALB request count or schedule

5. **Static Files**
   - Django static assets → S3 + CloudFront
   - React build served from ECS (or optionally S3)

## Security Groups

- **ALB SG**: Allow 80/443 from internet
- **ECS SG**: Allow traffic from ALB only
- **PostgreSQL SG**: Allow 5432 from ECS SG only
